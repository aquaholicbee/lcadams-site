3. Qui animera avec vous?

Indiquez ici les personnes qui font déjà partie de votre proposition. Vous pouvez laisser ces champs vides.

Si vous avez déjà prévu d’animer avec un autre parent ou adulte, indiquez son nom ici.

Petit rappel : les ateliers sont aussi une occasion pour les élèves de développer leur autonomie. Lorsque possible, nous encourageons donc les parents à animer indépendamment de leur propre enfant. La co-animation parent-enfant est surtout destinée aux élèves du 1er cycle ou lorsqu’elle est particulièrement pertinente à l’activité.

4. Autre chose?

Une soumission est une proposition, et non une inscription confirmée. Le comité Ateliers vous confirmera ensuite la date, le local et les rôles.
